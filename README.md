# Ralph Breaks the Internet

## Overview

When the steering wheel on *Sugar Rush* breaks, **Wreck-It Ralph** and **Vanellope von Schweetz** leave Litwak's Arcade and enter the uncharted world of the *Internet*!

---

### Main Characters

1. **Wreck-It Ralph** - The arcade game bad guy with a huge heart.
2. **Vanellope von Schweetz** - The energetic racer looking for new thrills.
3. **Shank** - The cool, tough driver from the online game *Slaughter Race*.

---

### Plot Highlights

- **The Quest:** Save *Sugar Rush* before the game gets unplugged.
- **The Challenge:** Raise `$27,500` on eBay to buy the replacement part.
- **The Journey:** Upload viral videos on `BuzzzTube` to earn Hearts and cash!

---

### Key Quotes
